# Release Notes - Version 8.0.65

**Release Date:** 2026-08-31

## Overview

`mcli ci preflight` now keeps the GitHub runner architecture consistent with
the container architecture selected for `act` on Apple Silicon. Previously,
the gate forced an amd64-only runner image, making Elixir compilation and
Dialyzer run through QEMU. Real Conduit jobs exhausted memory or segfaulted
inside the emulator before reaching their assertions.

## Before / After

**Before**

```mermaid
flowchart LR
    A[Apple Silicon host] --> B[amd64 act container]
    B --> C[amd64-only runner image]
    C --> D[QEMU emulates BEAM]
    D --> E[OOM or PLT segfault]
```

**After**

```mermaid
flowchart LR
    A[Apple Silicon host] --> B[native arm64 act container]
    B --> C[RUNNER_ARCH ARM64]
    C --> D[Multi-arch act runner image]
    D --> E[BEAM and Dialyzer run natively]
```

## Changes

- Apple Silicon now selects `--container-architecture linux/arm64` and passes
  `RUNNER_ARCH=ARM64` to the local workflow.
- `ubuntu-latest` maps to the multi-arch
  `catthehacker/ubuntu:act-20.04` runner image on that path, providing the
  general-purpose runner toolchain without emulation.
- Native Linux hosts and workflows without an architecture override are
  unchanged.
- Regression coverage verifies both flags remain aligned.

## Validation

- `tests/unit/workflow/test_ci_act_runner.py`: 39 passed.
- The Conduit workflow now selects the arm64 Erlang/OTP build and runs BEAM
  natively inside its local CI container.

## Upgrade Guide

No configuration change is required.
